# Week 01 学习总结

## 本周主题

本周是人工智能学习计划的第一周，主要目标是建立 Python 数据分析和机器学习入门基础。

## 本周完成内容

### Python 基础

我复习了变量、列表、字典、条件判断、循环和函数，并完成了学生成绩相关的小练习。

### NumPy

我学习了如何创建数组、计算平均值、最大值、最小值、总和，以及如何筛选数组中的数据。

### Pandas

我学习了如何读取 CSV 文件，如何使用 DataFrame 处理表格数据，如何新增列、筛选数据、排序数据，并保存处理结果。

### Matplotlib

我学习了如何用柱状图、折线图和子图展示学生成绩数据，并将图表保存为图片。

### 线性回归

我完成了一个房价预测模型，理解了特征 X、标签 y、训练集、测试集、模型训练和模型预测。

我还学习了 MAE、MSE 和 R2 这些模型评估指标。

### 分类模型

我完成了鸢尾花分类模型，理解了分类任务、逻辑回归、准确率、分类报告和混淆矩阵。

## 本周完成的项目

### 1. 学生成绩分析

使用 Pandas 读取学生成绩表，计算总分、平均分，并进行排序和筛选。

### 2. 学生成绩可视化

使用 Matplotlib 绘制学生总分柱状图、课程平均分柱状图和 Python 成绩折线图。

### 3. 房价预测

使用 LinearRegression 根据面积、房间数、距离市中心距离和房龄预测房价。

### 4. 鸢尾花分类

使用 LogisticRegression 根据鸢尾花的四个特征预测鸢尾花类别。
