## 项目简历描述

项目名称：学生成绩分析与挂科风险预测系统

项目描述：

基于学生成绩、学习时间和缺勤次数等数据，构建机器学习分类模型预测学生挂科风险。项目完成了数据读取、特征工程、模型训练、多模型对比、风险概率预测、风险等级划分和可视化展示。

使用技术：

Python、Pandas、Matplotlib、Scikit-learn、RandomForestClassifier、LogisticRegression、KNN、DecisionTreeClassifier

项目亮点：

- 使用 Pandas 完成学生成绩数据清洗与特征构造
- 构造 total、average 等特征用于模型训练
- 对比逻辑回归、决策树、随机森林和 KNN 多个分类模型
- 使用随机森林输出挂科概率和风险等级
- 使用 Matplotlib 绘制成绩分布、缺勤关系和模型对比图
- 整理 README 和项目总结文档，形成完整 GitHub 项目

## 面试时可以这样说

这个项目是我学习机器学习后做的第一个完整小项目。  
我用学生成绩、学习时间和缺勤次数作为特征，预测学生是否有挂科风险。

项目中我先用 Pandas 读取和处理数据，构造了总分和平均分两个新特征。然后用 Scikit-learn 对比了逻辑回归、决策树、随机森林和 KNN 等模型。最后选择随机森林作为最终模型，输出每个学生的挂科概率，并根据概率划分为高、中、低风险。

这个项目让我理解了完整机器学习项目流程，包括数据处理、特征工程、模型训练、模型评估、预测结果解释和项目文档整理。
